# HDFS Storage & Ingestion

This document details the HDFS storage structure and the initial data ingestion process for the TrafficLens project (Student 1).

## HDFS Directory Structure
The HDFS structure is designed to segregate data based on its processing stage:

- `/trafficlens/raw` : Stores raw, unmodified datasets ingested directly from the local filesystem.
- `/trafficlens/clean` : Stores pre-processed and cleaned data.
- `/trafficlens/analytics` : Stores data outputs generated by analytics and MapReduce jobs.
- `/trafficlens/export` : Stores aggregated results ready for export to external systems or visualization dashboards.
- `/trafficlens/ml` : Stores datasets and features specifically prepared for Machine Learning models.
- `/trafficlens/quarantine` : Stores corrupt, malformed, or rejected data that failed validation during ingestion or processing.

## Dataset Ingestion
The dataset for this project is the **METR-LA** traffic dataset.

- **Dataset**: METR-LA
- **Source Location (Local)**: `./dataset/metr-la.h5`
- **Destination (HDFS)**: `/trafficlens/raw/metr-la.h5`

## Ingestion Process
While the actual initial ingestion for this setup was performed manually via `docker exec` (transferring `/tmp/metr-la.h5` into HDFS), a reproducible shell script has been created for future automated deployments to set up the HDFS structure and ingest the data natively without Docker dependencies.

**Script**: `src/ingestion/ingest_to_hdfs.sh`

### How to Run the Ingestion
To run the ingestion process, execute the following command from the repository root:
```bash
bash src/ingestion/ingest_to_hdfs.sh
```

### Verifying HDFS Contents
You can verify the HDFS directory structure and the ingested file using the following Hadoop commands:

1. **Check Directory Structure**:
```bash
hdfs dfs -ls -h /trafficlens
```

2. **Check Ingested Data Details**:
```bash
hdfs dfs -ls -h /trafficlens/raw
hdfs dfs -du -h /trafficlens/raw
```
